# 安装与使用

## 首次安装

从仓库 Releases 下载 ZIP，解压并打开 PromptBridge。这是自签名、未公证的应用。如果 macOS 拦截打开，在尝试打开后进入“系统设置 → 隐私与安全性”，找到该应用并选择“仍要打开”。仅对从本仓库获取并确认来源的应用执行此操作；参见 [Apple 的说明](https://support.apple.com/102445)。

1. 在“模型连接”填写服务并保存。没有可用模型时不会生成结果。
2. 在“翻译与浮窗 → 输入框接入”点击“安装并启用”。应用复制到当前用户的 `~/Applications/PromptBridge.app`，辅助组件安装在相邻目录。
3. 点击“辅助功能权限…”，在系统中允许 **PromptBridge Accessibility**。
4. 以后从用户“应用程序”目录启动 PromptBridge。当前下载副本的草稿不会因安装自动关闭；使用完后退出该副本。

用户级服务注册在 `~/Library/LaunchAgents/local.promptbridge.accessibility.plist`，由系统按需启动。无需 Python、Swift 或管理员安装脚本。

## 翻译输入框

点击目标输入框，按 ⌥T 或点击浮窗。Auto 默认开启，译文生成后替换全文；关闭 Auto 后可以先编辑译文再确认。所有路径都不会发送宿主消息。

如果输入框已变化，重新聚焦并读取；旧稿和可用译文仍可复制。没有足够能力直接替换的输入框会提示复制使用，不会强行写入。

## CLI

在“CLI 接入”启用 Claude Code 或 Codex，然后新开 macOS Terminal 会话并照常启动对应命令。应用保持原参数和配置。

浮窗读取通过当前 CLI 的外部编辑器入口交接草稿。需要时授权 Terminal 自动化权限；如果单次快捷键未交接，可以在 CLI 中手动打开外部编辑器，不会自动连续重试。

首版以 macOS Terminal、zsh 和宿主原生 CLI 为接入路径。其他终端、远程会话和包装启动器不在本版已验证范围。剪贴板文字可通过浮窗更多菜单的 CLI 次级入口导入。

## 更新与修复

下载完整新版并打开。退出其他 PromptBridge 实例，结束正在进行的翻译或 CLI 编辑，再点击“安装并启用”或“修复接入”。已安装副本中的“修复接入”只修复配套组件，不原地替换运行中的自身。

更新前检查应用与组件签名，安装失败时尝试恢复原配套组合。存在旧文件的更新会在用户 Applications 目录保留隐藏的 `.PromptBridge-install-*` 备份；若提示回滚未完成，保留该备份并根据错误路径检查，不反复删除文件。

旧安装声明的模型与偏好会迁到用户配置目录；目标已经存在时不覆盖，原文件保留。若原 Key 仅通过进程环境提供，请在设置中重新保存。

## 停用和卸载

“翻译与浮窗 → 输入框接入 → 停用接入”移除辅助服务与 CLI 接入，保留模型配置与主应用。之后仍可直接输入翻译。退出应用后可移除主应用；是否删除本地配置由你决定。

## 常见问题

- **未连接**：检查输入框接入是否已安装，再使用修复接入。
- **权限不足**：为辅助组件授权；Terminal 的自动化权限与辅助功能权限分别设置。
- **目标已变化**：重新点击目标输入框并读取，不复用旧的替换关联。
- **未收到 CLI 草稿**：确认当前是可编辑状态，或使用宿主手动外部编辑器入口。
- **文件冲突 / 返回失败**：按具体提示处理；译文保留，不因失败自动重复写回。
- **无法打开或提示包损坏**：重新下载并核对校验文件；不要关闭 Gatekeeper 或使用来源不明的重签包。
