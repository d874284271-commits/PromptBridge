## 预发布待验项

- 另一台未安装过 PromptBridge、没有作者证书或配置的 Mac：首次打开、首次权限申请、安装及卸载。
- 本次最终签名包在真实桌面宿主和 Claude Code / Codex CLI 中的完整读取、翻译、替换、返回链；本轮未发起真实模型请求或发送宿主消息。
- macOS 14 的独立实机环境，以及未覆盖的多屏与系统辅助功能组合。

本版不因这些待验项关闭宿主接入，也不把历史版本在微信、QQ、Claude 等环境的记录自动标成本版通过。遇到无法替换的控件可保留译文复制使用。
