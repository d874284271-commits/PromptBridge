# ADR-0007：接入按实际操作能力判断，配置与版本不作白名单

后续操作规则：同日用户进一步要求默认 Auto，桌面与 CLI 一次点击读取整稿、翻译并覆盖。人工分步确认仅在关闭 Auto 后使用，见 [ADR-0008](0008-one-click-auto.md)。下文保留此决定当时的范围。

2026-10-10，用户确认。原则适用于整个项目，本轮实施覆盖 Codex CLI 与 Claude Code。扩展 ADR-0005 的运行时能力原则；取代 CLI 文档中以精确版本、整份配置和人工验收名单禁止尝试的规则。

正常运行的宿主允许尝试接入。版本、build、配置目录、未知配置节、插件与通知仅作诊断，不预审整份配置。是否完成读取或保存由当前权限、目标身份、官方编辑器交接、文件一致性及实际回执判断。“未验收”描述证据，不作为功能开关。

CLI 按钮默认尝试一次 Ctrl+G，保留手动官方编辑器入口；不解析或修改自定义键位，15 秒未收到交接则说明实际断点，不重试。读取、翻译、写回分别由用户触发，不发送消息。身份、权限、写回冲突、取消和单次提交检查保持。

当前实现仍使用本机 macOS Terminal、zsh、原生 CLI 可执行入口和官方外部编辑器，不新增 Node/shell 启动器跟踪、其他终端或远程会话能力。版本更新允许尝试，不等于任何版本已实机通过；实机结果独立记录。

长期开发规则位于项目 [AGENTS.md](../../AGENTS.md)，当前使用见 [安装与 CLI 接入](../installation.md)。旧验收记录保留历史含义。
