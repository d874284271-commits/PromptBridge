# ADR-0008：小窗默认执行 Auto 链路

日期：2026-10-10。状态：已决定。

用户明确要求桌面和 CLI 小窗默认开启 Auto。一次点击授权读取完整输入稿、翻译并覆盖；无需人工核验后再确认覆盖。翻译与入口设置提供关闭选项，关闭后保留原有人工确认流程。旧偏好文件缺少新字段时默认开启，明确保存的关闭选择保持关闭。

桌面继续使用现有完整输入框捕获与写回接口；CLI 继续使用一次 Ctrl+G 和官方外部编辑器交接。复用已有目标、文件一致性、取消、提交与返回规则。翻译失败、目标变化或冲突时停止，不重读、不重试、不发送。只有本次点击对应的稿件可以自动提交。手动发来的 CLI 请求仍须点击接入，接入点击也可执行 Auto。

Auto 使用紧凑进度窗，不激活编辑页。测试宿主仅供明确的开发菜单与隔离验证使用，不随主应用激活出现。实机重新载入与返回结果单独记录；未实测不关闭入口。

此决定更新 ADR-0007 和 CLI 计划中“翻译、保存分别确认”的当前操作规则；原记录作为历史保留。
