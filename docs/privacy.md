# 隐私与数据

点击浮窗或按快捷键后，PromptBridge 读取当前输入框的整份未发送草稿；直接输入模式使用你在浮窗中填写的文字。浮窗跟随焦点时只检查定位需要的应用、窗口和控件信息，不预读正文。

## 模型请求

生成译文时，当前原文、目标语言和所选翻译模板发送到你配置的模型服务。API Key 用于向该服务鉴权。服务地址由你选择，数据处理和计费遵循该服务的政策。应用没有 PromptBridge 中转服务器，不发送聊天历史。

选择“翻译并优化表达”使用相应模板，不额外读取外部资料。读取、翻译和替换不会发送宿主消息，也不会因为超时自动重试。

## 本地数据

供应商、API Key 和偏好保存在 `~/Library/Application Support/PromptBridge/`。Key 随配置以明文保存，供应商配置文件权限为仅当前用户读写（0600）；当前版本不使用 Keychain 存储这些 Key。

当前草稿、译文和替换记录保留在应用内存，退出后清空。CLI 接入在用户目录保存启动接入文件与会话注册元数据，并通过宿主外部编辑器的临时文件交接草稿；取消不写回译文。

“复制”会把译文放到系统剪贴板，其他可读取剪贴板的应用可能访问它。通用输入框适配在必要时借助剪贴板读取或替换文字，并按操作前后状态处理剪贴板恢复。

## 权限与日志

辅助功能权限用于定位、读取和替换输入框；Terminal 自动化权限用于定位并返回原 CLI 标签页。模型网络请求由主应用完成，辅助组件不读取模型配置。

应用没有使用统计或远程崩溃上报。系统可能记录进程状态和错误；公开反馈请去掉用户名、路径、Key 和真实草稿。

停用接入会移除辅助服务和 CLI 接入，保留模型配置。需要清空配置时，请先退出应用，再删除上述配置目录。
