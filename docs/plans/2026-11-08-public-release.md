# PromptBridge v0.9.0 首次公开发布

用户已批准实施：macOS 14+、Apple Silicon、中文界面；GitHub 源码与未公证下载包，Apache-2.0；从清理后的快照建立公开仓库，本地历史与既有改动保留。

## 产品契约

- 保留桌面整稿翻译/优化、直接输入、Auto（默认开）、编辑/复制/返回/恢复，以及 Claude Code、Codex CLI 接入。遵守 AGENTS.md、ADR-0007/0008，不发送消息、不增加宿主版本白名单。
- 正式应用去除测试宿主、演示译器、验收启动参数和开发菜单。测试构建显式启用 `PROMPTBRIDGE_TESTING`。无有效模型进入设置，不生成示例结果。
- 沿用品牌与 390 pt 浮窗。原文/译文各自 72–220 pt 随内容伸缩，整窗最大 min(680, 屏幕可用高度−24)，底部操作保持可达，超限编辑区独立滚动，短稿可缩回。
- 更多菜单只显示真实保存的草稿；配置、模板与 CLI 高级操作按需展开。

1. RELEASE-1：配置迁到用户 Application Support；实际签名身份校验；内嵌辅助组件和原生用户级安装/修复/卸载。验证无开发目录条件下可启动、保存配置、连接辅助服务。

3. RELEASE-3（依赖 1/2）：公开文档、Apache-2.0、CI、快照导出与发布包；干净检出构建和包内隐私检查。
4. RELEASE-4（依赖 3）：独立变更审查、针对性回归、真实下载包安装/桌面/CLI验收；逐项记录通过或外部条件缺失。真实 GitHub 发布需确定目标仓库及可用账号。

## 分发与接口决策

- 不购买 Apple 开发者计划；发布为未公证应用，文档指向系统允许打开流程，不关闭 Gatekeeper。
- 继续用户级 LaunchAgent、固定用户 Applications 安装位置、IPC 3 / CLI editor 2。主/辅助进程按实际签名证书及 bundle ID 相互验证；自构建可使用自己的证书。
- 旧配置仅从既有已验证安装声明的路径迁移，目标已存在不覆盖，源文件保留。模型与偏好不随卸载默认删除。
- 测试、日志与本机资料不进入公开产物；稳定签名私钥留在发布环境。
